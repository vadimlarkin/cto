# CTO проекта

## Запуск из проектного чата

Вызов `$cto` означает, что Вадим поручает открыть отдельный чат CTO в текущем проекте. Если навык подобран автоматически, используй создание чата по прямому поручению пользователя. На вопросы о настройке и состоянии навыка отвечай в текущем чате. Для запроса только на рекомендации по развитию прочитай [режим предложений](references/review-and-strategy.md) и ответь в текущем проектном чате, если пользователь не поручил открыть отдельный.

1. Найди профильные инструменты Codex для списка проектов, создания и чтения чатов. Сверь проект исходного чата с доступным проектом Codex. При неоднозначности установи проект по контексту поручения или уточни его. Название нового чата — `CTO проекта <название проекта>`. Используй явно указанное Вадимом имя этого проекта или его отображаемое имя в Codex.
2. Выбери сильнейшую подтверждённо доступную модель с поддержкой `high`. Исходная модель — `gpt-6.2-astra`. При наличии подтверждённого официального преемника с `high` выбери его. Если основная модель недоступна, самостоятельно выбери сильнейшую из подтверждённых запасных с `high`. Ориентируйся на доступность в Codex и назначение модели. Если подходящую модель нельзя подтвердить или запустить, сообщи причину. По умолчанию проверяй список моделей и уровней рассуждения в доступных инструментах Codex.
3. Сверь существующие чаты и записи о запуске для того же поручения. Если есть CTO с этой работой, продолжи через подтверждённый способ передачи поручения. При неизвестном исходе передачи сначала сверь историю целевого чата. Перед созданием нового чата сохрани намерение запуска с проектом и ссылкой на исходное поручение в принятом журнале проекта или в исходном чате. Передай при создании идентификатор того же проекта, выбранную модель и `thinking: high`.
4. В первый ход передай задачу пользователя, её границы, ссылку на исходное поручение, выбранные параметры запуска и абсолютный путь к [инструкции чата CTO](references/role.md) из установленной копии. Поручи чату прочитать её и применить подходящий режим. Зафиксируй полученный идентификатор. Если Codex ещё готовит чат или ответ потерялся, найди результат по проекту и исходному поручению. Укажи, что запуск проверяется, пока исход неизвестен. Повторяй создание только после подтверждения, что предыдущая попытка не создала чат.

В чате, уже запущенном как CTO, продолжай поручение по [инструкции чата CTO](references/role.md).
