# CTO проекта

Перед любым поручением исполнителю применяй [правила запуска](references/role.md#запуск-исполнителя), в том числе при подготовке рекомендаций без отдельного чата CTO.

## Запуск из проектного чата

Вызов `$cto` означает, что Вадим поручает открыть отдельный чат CTO в текущем проекте. Если навык подобран автоматически, используй создание чата по прямому поручению пользователя. На вопросы о настройке и состоянии навыка отвечай в текущем чате. Для запроса только на рекомендации по развитию поручи подготовку субагенту или уже назначенному рабочему чату по [режиму предложений](references/review-and-strategy.md). Новый рабочий чат открывай по прямому поручению. Прими рекомендацию и сообщи её в текущем проектном чате, если пользователь не поручил открыть отдельный чат CTO.

1. Найди профильные инструменты Codex для списка проектов, создания и чтения чатов. Сверь проект исходного чата с доступным проектом Codex. При неоднозначности установи проект по контексту поручения или уточни его. Название нового чата — `CTO проекта <название проекта>`. Используй явно указанное Вадимом имя этого проекта или его отображаемое имя в Codex.
2. Для ведущего чата CTO используй только `gpt-6.2-sol` с уровнем рассуждения `high`. Сверь доступность профиля и возможность явно передать оба параметра. Если профиль недоступен, сообщи причину и останови запуск.
3. Сверь существующие чаты и записи о запуске для того же поручения. Возобновляй работу только в неархивированном чате CTO с подтверждённым профилем `gpt-6.2-sol` и `high`. При неизвестном исходе передачи сначала сверь историю целевого чата. Перед созданием нового чата сохрани намерение запуска с проектом и ссылкой на исходное поручение в принятом журнале проекта или в исходном чате. Передай при создании идентификатор того же проекта, `model: "gpt-6.2-sol"` и `thinking: "high"`.
4. В первый ход передай задачу пользователя, её границы, ссылку на исходное поручение, выбранные параметры запуска и абсолютный путь к [инструкции чата CTO](references/role.md) из установленной копии. Поручи чату прочитать её и применить подходящий режим. Зафиксируй полученный идентификатор. Если Codex ещё готовит чат или ответ потерялся, найди результат по проекту и исходному поручению. Укажи, что запуск проверяется, пока исход неизвестен. Повторяй создание только после подтверждения, что предыдущая попытка не создала чат.

В чате, уже запущенном как CTO, продолжай поручение по [инструкции чата CTO](references/role.md).
